= Delete a WebAuthn credentials entry

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/security/webauthn/credentials/{owner.uuid}/{username}/{index}/{relying_party.id}`#

*Introduced In:* 9.16

Deletes a WebAuthn credentials entry.

== Required properties

***** `owner.uuid`

***** `username`

***** `index`

***** `relying_party.id`

== Related ONTAP commands

* `security webauthn credentials delete`
