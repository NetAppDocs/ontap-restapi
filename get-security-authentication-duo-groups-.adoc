= Retrieve the Duo group configured for an SVM or cluster

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/authentication/duo/groups/{owner.uuid}/{name}`#

*Introduced In:* 9.14

Retrieves the Duo group configured for an SVM or cluster.

== Related ONTAP commands

* `security login duo group show`

== Learn more

* link:security_authentication_duo_groups_owner.uuid_name_endpoint_overview.htmll[DOC /security/authentication/duo/groups/{owner.uuid}/\{name}]
* link:security_accounts_endpoint_overview.html[DOC /security/accounts]

|Type

|Required
|Description

|string
|path
