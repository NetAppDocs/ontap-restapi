= Delete a LUN attribute

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/storage/luns/{lun.uuid}/attributes/{name}`#

*Introduced In:* 9.10

Deletes a LUN attribute.
