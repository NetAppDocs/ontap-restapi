= Retrieve a resource for a tag

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/resource-tags/{resource_tag.value}/resources/{href}`#

*Introduced In:* 9.13

Retrieves a specific resource for a specific tag.


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|resource_tag.value
|string
|path
|True
a|* format: key:value


|href
|string
|path
|True
a|

|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|href
|string
a|This property provides the address in the API at which the tagged resource is available. Additional queries can be made on this
endpoint to fetch the resource's properties.


|label
|string
a|This is a human-readable classifier representing the type of thing that is pointed to by the href.


|svm
|link:#svm[svm]
a|If the tagged resource belongs to an SVM, this property will be set. If the resource does not belong to an SVM (i.e. it belongs
to the cluster as a whole), then this property will be empty and unreturned.


|value
|string
a|The text value of the tag formatted as `key:value`.


|===


.Example response
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "href": "string",
  "label": "volume",
  "svm": {
    "_links": {
      "self": {
        "href": "/api/resourcelink"
      }
    },
    "name": "svm1",
    "uuid": "02c9e252-41be-11e9-81d5-00a0986138f7"
  },
  "value": "string"
}
====
