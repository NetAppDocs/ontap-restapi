= Delete a CIFS share

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/protocols/cifs/shares/{svm.uuid}/{name}`#

*Introduced In:* 9.6

Deletes a CIFS share.

== Related ONTAP commands

* `vserver cifs share delete`

== Learn more

* link:protocols_cifs_shares_endpoint_overview.html[DOC /protocols/cifs/shares]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|name
|string
|path
|True
a|Share Name


|svm.uuid
|string
|path
|True
a|UUID of the SVM to which this object belongs.

|===

