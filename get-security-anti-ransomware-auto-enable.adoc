= Retrieve anti-ransomware auto enablement values

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/anti-ransomware/auto-enable`#

*Introduced In:* 9.18

Retrieves the current anti-ransomware auto enablement values, including details about warm-up period and auto enablement setting for new and existing volumes.


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|_links
|link:#self_link[self_link]
a|

|new_volume_auto_enable
|boolean
a|Auto Anti-Ransomware Protection (ARP) setting for new volumes.


|warm_up_period_applicable
|boolean
a|Indicates if the warm-up period is applicable.


|warm_up_period_completed
|boolean
a|Indicates if warm-up period has completed.


|warm_up_period_remaining_duration
|string
a|Time remaining for warm-up period completion.


|warm_up_period_total_duration
|string
a|Duration of warm-up period.


|===
