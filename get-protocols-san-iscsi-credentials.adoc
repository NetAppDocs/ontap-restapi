= Retrieve iSCSI credentials

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/san/iscsi/credentials`#

*Introduced In:* 9.6

Retrieves iSCSI credentials.

== Related ONTAP commands

* `vserver iscsi security show`

== Learn more

* link:protocols_san_iscsi_credentials_endpoint_overview.html[DOC /protocols/san/iscsi/credentials]
