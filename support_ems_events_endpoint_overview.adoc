= Retrieve events



== Overview

Queries a live collection of observed events on the system.
Note: The `filter.name` parameter is used to pass a filter to be applied to the event collection returned. To retrieve the list of available filters, refer to <</docs/support/ems_filter_collection_get,/support/ems/filters>>

== Example

=== Querying for the latest event received by EMS

[,json]
----

# The API:
GET /api/support/ems/events

# The call:
curl -X GET "https://<mgmt-ip>/api/support/ems/events?fields=message.name&max_records=1" -H "accept: application/hal+json"

# The response:
200 OK

# JSON Body
