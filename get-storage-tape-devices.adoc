= Retrieve tape devices

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/storage/tape-devices`#

*Introduced In:* 9.9

Retrieves a collection of tape devices.

== Related ONTAP commands

* `storage tape show`

== Learn more
