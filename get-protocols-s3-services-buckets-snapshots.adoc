= Retrieve a collection of S3 bucket snapshots

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/s3/services/{svm.uuid}/buckets/{s3_bucket.uuid}/snapshots`#

*Introduced In:* 9.16

Retrieves a collection of S3 bucket snapshots.

== Related ONTAP commands

* `vserver object-store-server bucket snapshot show`

== Learn more

* link:protocols_s3_services_svm.uuid_buckets_s3_bucket.uuid_snapshots_endpoint_overview.html[DOC /protocols/s3/services/{svm.uuid}/buckets/{s3_bucket.uuid}/snapshots]

|query
|False

|return_records
|boolean
|query
|False
a|The default is true for GET calls.  When set to false, only the number of records is returned.

|integer
|query
|False

* Default value: 15
* Max value: 120
* Min value: 0


|order_by
|array[string]
|query
|False
a|Order results by specified fields and optional [asc|desc] direction. Default direction is 'asc' for ascending.
