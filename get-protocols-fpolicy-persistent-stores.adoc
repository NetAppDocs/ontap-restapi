= Retrieve the FPolicy persistent store configurations for an SVM

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/fpolicy/{svm.uuid}/persistent-stores`#

*Introduced In:* 9.14

Retrieves FPolicy Persistent Store configurations for a specified SVM.

== Related ONTAP commands

* `fpolicy persistent-store show`

== Learn more

* link:protocols_fpolicy_svm.uuid_persistent-stores_endpoint_overview.html[DOC /protocols/fpolicy/{svm.uuid}/persistent-stores]
