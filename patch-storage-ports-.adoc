= Update a storage port

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/storage/ports/{node.uuid}/{name}`#

*Introduced In:* 9.11

Updates a storage port.

== Related ONTAP commands

* `storage port modify`
* `storage port enable`
* `storage port disable`

== Learn more

* link:storage_ports_endpoint_overview.html[DOC /storage/ports]

|Description

|path

|name
|string
|path
|True
a|Port name

|===
