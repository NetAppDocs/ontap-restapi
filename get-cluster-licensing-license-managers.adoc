= Retrieve license managers

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/cluster/licensing/license-managers`#

*Introduced In:* 9.8

Retrieves a collection of license managers.

== Learn more

* link:cluster_licensing_license-managers_endpoint_overview.html[DOC /cluster/licensing/license-managers]

== Related ONTAP commands

* `system license license-manager show`
