= Create a local UNIX group configuration for an SVM

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/name-services/unix-groups`#

*Introduced In:* 9.9

Creates the local UNIX group configuration for the specified SVM.

Group name and group ID are mandatory parameters.

== Important notes

* The default limit for local UNIX groups and group members is 32768.

== Learn more

* link:name-services_unix-groups_endpoint_overview.html[DOC /name-services/unix-groups]

== Request Body

                

[cols=3*,options=header]
|===
|Name
|Type
|Description

|id
|integer
a|UNIX group ID of the specified user.


|name
|string
a|UNIX group name to be added to the local database.


|skip_name_validation
|boolean
a|Indicates whether or not the validation for the specified UNIX group name is disabled.


|svm
|link:#svm[svm]
a|SVM, applies only to SVM-scoped objects.

|array[link:#users[users]]
a|

|===

== Error


ONTAP Error Response Codes

|===
| Error Code | Description

| 2621706
| The specified SVM UUID is incorrect for the specified SVM name.

| 2621516
| This operation is only supported on a data SVM.

| 3277025
| Maximum supported limit of UNIX group count reached.

| 3277051
| Invalid characters in group name. Valid characters are 0-9, A-Z, a-z, ".", "_" and "-". Names cannot start with "-".

| 23724067
| Group name too long. Maximum supported length is 64 characters.

| 23724141
| Duplicate group ID. Group ID must be unique.
|===
