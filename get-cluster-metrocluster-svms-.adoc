= Retrieve configuration information for an SVM

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/cluster/metrocluster/svms/{cluster.uuid}/{svm.uuid}`#

*Introduced In:* 9.11

Retrieves configuration information for an SVM in a MetroCluster relationship.


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|cluster.uuid
|string
|path
|True
a|Cluster ID


|svm.uuid
|string
|path
|True
a|SVM UUID


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===
