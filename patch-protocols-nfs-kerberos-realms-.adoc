= Update Kerberos realm properties

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/protocols/nfs/kerberos/realms/{svm.uuid}/{name}`#

*Introduced In:* 9.6

Updates the properties of a Kerberos realm.

* `vserver nfs kerberos realm modify`

== Learn more

* link:protocols_nfs_kerberos_realms_endpoint_overview.html[DOC /protocols/nfs/kerberos/realms]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|svm.uuid
|string
|path
|True
a|SVM UUID


|name
|string
|path
|True
a|Kerberos realm

|===

.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "ad_server": {
    "address": "1.2.3.4",
    "name": "string"
  },
  "admin_server": {
    "address": "1.2.3.4"
  },
  "comment": "string",
  "encryption_types": [
    "string"
  ],
  "kdc": {
    "ip": "1.2.3.4",
    "port": 88,
    "vendor": "string"
  },
  "name": "string",
  "password_server": {
    "address": "1.2.3.4"
  },
  "svm": {
    "name": "svm1",
    "uuid": "02c9e252-41be-11e9-81d5-00a0986138f7"
  }
}
====
