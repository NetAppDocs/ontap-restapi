= Retrieve an NFS over TLS interface configuration

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/nfs/tls/interfaces/{interface.uuid}`#

*Introduced In:* 9.15

Retrieves an NFS over TLS interface.

== Related ONTAP commands

* `vserver nfs tls interface show`

== Learn more

* link:protocols_nfs_tls_interfaces_endpoint_overview.html[DOC /protocols/nfs/tls/interfaces]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|interface.uuid
|string
|path
|True
a|Network interface UUID.


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|_links
|link:#_links[_links]
a|

|certificate
|link:#certificate[certificate]
a|Specifies the certificate that is used for creating NFS over TLS connections.


|enabled
|boolean
a|Indicates whether NFS over TLS is enabled.


|enforce_host_authentication
|boolean
a|Indicates whether NFS over TLS host authentication is enforced or not.


|interface
|link:#interface[interface]
a|Network interface.


|svm
|link:#svm[svm]
a|SVM, applies only to SVM-scoped objects.


|===
