= Update UNIX group information for a group in an SVM

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/name-services/unix-groups/{svm.uuid}/{name}`#

*Introduced In:* 9.9

Updates the UNIX group information of the specified group in the specified SVM.

== Learn more

* link:name-services_unix-groups_endpoint_overview.html[DOC /name-services/unix-groups]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|name
|string
|path
|True
a|UNIX group name.


|svm.uuid
|string
|path
|True
a|UUID of the SVM to which this object belongs.

|===

== Request Body

                

[cols=3*,options=header]
|===
|Name
|Type
|Description

|id
|integer
a|UNIX group ID of the specified user.


|users
|array[link:#users[users]]
a|

|===
