= Modify the configuration for an automatic update

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/support/auto-update/configurations/{uuid}`#

*Introduced In:* 9.10

Updates the configuration for a specified automatic update.


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|uuid
|string
|path
|True
a|Unique identifier for configuration record.

|===

== Request Body

                

[cols=3*,options=header]
|===
|Name
|Type
|Description

|action
|string
a|The action to be taken by the alert source as specified by the user.


|category
|string
a|Category for the configuration row.


|uuid
|string
a|Unique identifier for the configuration row.


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "action": "confirm",
  "category": "disk_fw",
  "uuid": "572361f3-e769-439d-9c04-2ba48a08ff47"
}
====

== Response

```
Status: 200, Ok
```

== Error

```
Status: Default
```

ONTAP Error Response Codes

|===
| Error Code | Description

| 262179
| Unexpected argument.
|===
