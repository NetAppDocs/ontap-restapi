= Create an external-role-mapping entry

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/security/external-role-mappings`#

*Introduced In:* 9.16

Creates an external-role-mapping entry.

== Required properties

* `external_role`
* `provider`
* `ontap_role`

== Optional properties

* `comment`

== Related ONTAP commands

* `security login external-role-mapping create`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|return_records
|boolean
|query
|False
a|The default is false.  If set to true, the records are returned.

* Default value:

|===

== Request Body

                

[cols=3*,options=header]
|===
|Name
|Type
|Description

|comment
|string
a|Any comment regarding this external-role-mapping entry.


|external_role
|string
a|External Identity provider role.


|ontap_role
|link:#ontap_role[ontap_role]
a|ONTAP role to map with the external identity role.

* Introduced in: 9.16


|provider
|string
a|Type of the external identity provider.


|timestamp
|string
a|Date and time indicating when this external-role-mapping entry was created.


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "comment": "string",
  "external_role": "string",
  "ontap_role": {
    "name": "admin"
  },
  "provider": "string",
  "timestamp": "string"
}
====
