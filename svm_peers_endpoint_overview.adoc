= Manage SVM peer relationships
:imagesdir: ./media/

[.lead]
Manage SVM peering relationships to facilitate communication and resource sharing between different storage virtual machines. Use these endpoints to create, modify, and monitor peer connections for streamlined collaboration and data access.

== Managing SVM peers

The SVM peer commands allow you to create and manage SVM peering relationships.

=== SVM peer APIs

The following APIs are used to manage SVM peers:

* GET /api/svm/peers
* POST /api/svm/peers
* GET /api/svm/peers/\{uuid}
* PATCH /api/svm/peers/\{uuid}
* DELETE /api/svm/peers/\{uuid}
