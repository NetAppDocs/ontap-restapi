= Retrieve IP to hostname mappings for all SVMs in a cluster

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/name-services/local-hosts`#

*Introduced In:* 9.10

Retrieves all IP to hostname mappings for all SVMs of the cluster.

== Related ONTAP commands

* `vserver services name-service dns hosts show`

== Learn more

* link:name-services_local-hosts_endpoint_overview.html[DOC /name-services/local-hosts]
