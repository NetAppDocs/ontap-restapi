= Retrieve the lock for a specific UUID

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/locks/{uuid}`#

*Introduced In:* 9.10

Retrieves the lock for a specific UUID.

== Related ONTAP commands

* `vserver locks show`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|uuid
|string
|path
|True
a|Lock ID


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===
