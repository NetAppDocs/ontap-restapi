= Retrieve specific iSCSI credentials

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/san/iscsi/credentials/{svm.uuid}/{initiator}`#

*Introduced In:* 9.6

Retrieves specified iSCSI credentials.

== Related ONTAP commands

* `vserver iscsi security show`

== Learn more

* link:protocols_san_iscsi_credentials_endpoint_overview.html[DOC /protocols/san/iscsi/credentials]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|svm.uuid
|string
|path
|True
a|The unique identifier of an SVM.


|initiator
|string
|path
|True
a|The iSCSI initiator of the credentials object.


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|_links
|link:#_links[_links]
a|

|authentication_type
|string
a|The iSCSI authentication type. Required in POST; optional in PATCH.


|chap
|link:#chap[chap]
a|Challenge-Handshake Authentication Protocol (CHAP) credentials.


|initiator
|string
a|The iSCSI initiator to which the credentials apply. Required in POST.


|initiator_address
|link:#initiator_address[initiator_address]
a|Initiator address ranges.


|svm
|link:#svm[svm]
a|SVM, applies only to SVM-scoped objects.


|===
