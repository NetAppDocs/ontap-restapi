= Retrieve NDMP configurations for all SVMs

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/ndmp/svms`#

*Introduced In:* 9.7

Retrieves NDMP configurations for all SVMs.

== Related ONTAP commands

* `vserver services ndmp show`

== Learn more

* link:protocols_ndmp_svms_endpoint_overview.html[DOC /protocols/ndmp/svms]

|False
a|Order results by specified fields and optional [asc|desc] direction. Default direction is 'asc' for ascending.
