= Retrieve the CIFS connection information for all SVMs

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/cifs/connections`#

*Introduced In:* 9.11

Retrieves the CIFS connection information for all SVMs.

== Related ONTAP commands

*** `vserver cifs connection show`

== Learn more

* link:protocols_cifs_connections_endpoint_overview.html[DOC /protocols/cifs/connections]
