= Retrieve an applied restricted group policy for an SVM

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/cifs/group-policies/{svm.uuid}/restricted-groups/{policy_index}/{group_name}`#

*Introduced In:* 9.12

Retrieves applied policy of restricted group for specified SVM.

== Related ONTAP commands

* `vserver cifs group-policy restricted-group show-applied`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|policy_index
|integer
|path
|True
a|Group policy index.


|group_name
|string
|path
|True
a|Group name.


|svm.uuid
|string
|path
|True
a|UUID of the SVM to which this object belongs.


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===
