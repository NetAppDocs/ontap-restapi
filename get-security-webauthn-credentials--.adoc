= Retrieve a WebAuthn credentials entry

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/webauthn/credentials/{owner.uuid}/{username}/{index}/{relying_party.id}`#

*Introduced In:* 9.16

Retrieves a WebAuthn credentials entry.

== Related ONTAP commands

* `security webauthn credentials show`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|owner.uuid
|string
|path
|True
a|Used to identify a cluster or an SVM.


|username
|string
|path
|True
a|Username.


|index
|integer
|path
|True
a|Index.


|relying_party.id
|string
|path
|True
a|Relying Party ID.


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|_links
|link:#self_link[self_link]
a|

|creation_time
|string
a|Date and time indicating when this entry was created.


|credential
|link:#credential[credential]
a|

|display_name
|string
a|Display name.


|index
|integer
a|Index.


|last_used_time
|string
a|Date and time indicating when this entry was last used.


|owner
|link:#svm_reference[svm_reference]
a|SVM, applies only to SVM-scoped objects.


|public_key
|link:#public_key[public_key]
a|

|relying_party
|link:#relying_party[relying_party]
a|

|scope
|string
a|Scope of the entity. Set to "cluster" for cluster owned objects and to "svm" for SVM owned objects.


|username
|string
a|Username.


|===
