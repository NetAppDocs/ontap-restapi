= Retrieve a shelf

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/storage/shelves/{uid}`#

*Introduced In:* 9.6

Retrieves a specific shelf.

== Related ONTAP commands

* `storage shelf show`
* `storage shelf port show`
* `storage shelf drawer show`
* `storage shelf drawer show-slot`
* `storage shelf acp show`

== Learn more

* link:storage_shelves_endpoint_overview.html[DOC /storage/shelves]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|uid
|string
|path
|True
a|Shelf UID


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===
