= Retrieve storage ports

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/storage/ports`#

*Introduced In:* 9.6

Retrieves a collection of storage ports.

== Related ONTAP commands

* `storage port show`

== Learn more

* link:storage_ports_endpoint_overview.html[DOC /storage/ports]
