= Retrieve the configured groups

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/authentication/duo/groups`#

*Introduced In:* 9.14

Retrieves the configured groups.

== Related ONTAP commands

* `security login duo group show`

== Learn more

* link:security_authentication_duo_groups_endpoint_overview.html[DOC /security/authentication/duo/groups]
* link:security_accounts_endpoint_overview.html[DOC /security/accounts]
