= Retrieve the cluster network security configuration

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/cluster-network`#

*Introduced In:* 9.18

Retrieves the cluster network security configuration.

== Related ONTAP commands

* 'security cluster-network show'


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===


|===
|Name
|Type
|Description

|_links
|link:#self_link[self_link]
a|

|enabled
|boolean
a|Indicates whether cluster network security is enabled.


|mode
|string
a|The cluster network security mode.


|status
|string
a|The status of the cluster network security configuration.
