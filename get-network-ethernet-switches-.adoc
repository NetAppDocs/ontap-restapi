= Retrieve Ethernet switch details

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/network/ethernet/switches/{name}`#

*Introduced In:* 9.8

Retrieves the details of an Ethernet switch.

== Related ONTAP commands

* `system switch ethernet show`

== Learn more

* link:network_ethernet_switches_endpoint_overview.html[DOC /network/ethernet/switches]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|name
|string
|path
|True
a|Name


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

|Type
|Description

|discovered

* x-nullable: true

a|Model Number.


|monitoring

|name
|string
a|Name.


|network
|string
a|Switch Network.


|rcf_version
|string
a|The switch reference configuration file (RCF) version.


|role
|string
a|Switch role based on the interface configurations. Using '+' to combine multiple roles.
