= ONTAP REST API Storage endpoints
:imagesdir: ./media/

[.lead]
Manage physical and logical storage with the ONTAP storage APIs. These endpoints cover aggregates, volumes, LUNs, qtrees, snapshots, quotas, and storage efficiency to optimize and protect your storage resources.

== Overview

The ONTAP storage APIs can be used to manage physical and logical storage. This includes management of aggregates, volumes, LUNs, qtrees, snapshots, quotas, and storage efficiency.
