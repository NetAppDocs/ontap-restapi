= Retrieve Ethernet switches attached to a chassis

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/network/ethernet/switches`#

*Introduced In:* 9.8

Retrieves a collection of Ethernet switches.

== Related ONTAP commands

* `system switch ethernet show`

== Learn more

* link:network_ethernet_switches_endpoint_overview.html[DOC /network/ethernet/switches]
