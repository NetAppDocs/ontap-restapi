= Retrieve software installation requests history details

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/cluster/software/history`#

*Introduced In:* 9.6

Retrieves the history details for software installation requests.

== Related ONTAP commands

* `cluster image show-update-history`

== Learn more

* link:cluster_software_history_endpoint_overview.html[DOC /cluster/software/history]
