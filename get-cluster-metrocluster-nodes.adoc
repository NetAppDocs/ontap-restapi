= Retrieve MetroCluster nodes and configurations

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/cluster/metrocluster/nodes`#

*Introduced In:* 9.8

Retrieves MetroCluster nodes and their configurations.

== Related ONTAP Commands

* `metrocluster node show`

== Learn more

* link:cluster_metrocluster_nodes_endpoint_overview.html[DOC /cluster/metrocluster/nodes]
