= Retrieve a Vscan On-Demand policy

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/vscan/{svm.uuid}/on-demand-policies`#

*Introduced In:* 9.6

Retrieves the Vscan On-Demand policy.

== Related ONTAP commands

* `vserver vscan on-demand-task show`

== Learn more

* link:protocols_vscan_svm.uuid_on-demand-policies_endpoint_overview.html[DOC /protocols/vscan/{svm.uuid}/on-demand-policies]
