= Create an FC WWPN alias

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/network/fc/wwpn-aliases`#

*Introduced In:* 9.6

Creates an FC WWPN alias.

== Required properties

* `svm.uuid` or `svm.name` - Existing SVM in which to create the FC alias.
* `alias` - Name of the FC alias.
* `wwpn` - FC WWPN for which to create the alias.

== Related ONTAP commands

* `vserver fcp wwpn-alias set`

== Learn more

* link:network_fc_wwpn-aliases_endpoint_overview.html[DOC /network/fc/wwpn-aliases]

wwpn_alias
