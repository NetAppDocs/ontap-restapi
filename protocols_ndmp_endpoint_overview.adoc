= Manage NDMP mode



You can use this API to manage NDMP mode: SVM-scope or node-scope.

=== Examples

Updates NDMP mode to SVM:

----
 PATCH "/api/protocols/ndmp" '{"mode":"svm"}'
----

Updates NDMP mode to node:

----
 PATCH "/api/protocols/ndmp" '{"mode":"node"}'
----
