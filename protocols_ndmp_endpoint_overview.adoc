= Manage NDMP mode
:imagesdir: ./media/

[.lead]
Manage NDMP mode settings to configure either SVM-scope or node-scope for your ONTAP environment. Note that node-scope mode is deprecated and not supported on AFX and FSx platforms.

You can use this API to manage NDMP mode: SVM-scope or node-scope.
NDMP node scope mode is Deprecated. It is not supported on AFX and FSx platforms.

=== Examples

Updates NDMP mode to SVM:

----
 PATCH "/api/protocols/ndmp" '{"mode":"svm"}'
----

Updates NDMP mode to node:

----
 PATCH "/api/protocols/ndmp" '{"mode":"node"}'
----
