= Retrieve cluster network security certificate configuration

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/cluster-network/certificates`#

*Introduced In:* 9.18

Retrieves the certificate configuration used for cluster network security.

== Related ONTAP commands

* 'security cluster-network certificate show'
