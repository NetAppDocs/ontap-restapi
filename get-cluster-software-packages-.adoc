= Retrieve the software package information

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/cluster/software/packages/{version}`#

*Introduced In:* 9.6

Retrieves the software package information.

== Related ONTAP commands

* `cluster image package show-repository`

== Learn more

* link:cluster_software_packages_endpoint_overview.html[DOC /cluster/software/packages]

|===

|Name
|Type
|In
|Required
|Description

|version
|string
|path
|True
a|

|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

```
Status: 200, Ok
```

|Type
|Description

|_links

|string

* readOnly: 1
* Introduced in: 9.6
* x-nullable: true
