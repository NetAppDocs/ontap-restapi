= Retrieve the CIFS domain preferred DC configuration for an SVM

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/cifs/domains/{svm.uuid}/preferred-domain-controllers`#

*Introduced In:* 9.10

Retrieves the CIFS domain preferred DC configuration of an SVM.

== Related ONTAP commands

* `vserver cifs domain preferred-dc show`
* `vserver cifs domain preferred-dc check`

== Learn more

* link:protocols_cifs_domains_svm.uuid_preferred-domain-controllers_endpoint_overview.html[DOC /protocols/cifs/domains/{svm.uuid}/preferred-domain-controllers]
