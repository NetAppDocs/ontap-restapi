= Manage legal-hold operations
:imagesdir: ./media/

[.lead]
Use endpoints to manage legal-hold operations for specified litigation IDs. These operations include adding or removing legal holds on files, which is essential for compliance and data retention during legal proceedings.

Manages the legal-hold operations for the specified litigation ID.

=== Examples

. Adds a Legal-Hold.

----
 POST "/api/storage/snaplock/litigations/f8a67b60-4461-11e9-b327-0050568ebef5:l1/operations" '{"type" : "begin", "path" : "/a.txt"}'
----

. Removes a Legal-Hold.

----
 POST "/api/storage/snaplock/litigations/f8a67b60-4461-11e9-b327-0050568ebef5:l1/operations" '{"type" : "end", "path" : "/a.txt"}'
----
