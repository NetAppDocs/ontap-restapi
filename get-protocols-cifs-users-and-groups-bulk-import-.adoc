= Retrieve import operation status for CIFS local users, groups, and group memberships

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/cifs/users-and-groups/bulk-import/{svm.uuid}`#

*Introduced In:* 9.11

Retrieves information about the import operation status of the CIFS local users,
groups, and group memberships.

== Related ONTAP commands

* `vserver cifs users-and-groups import get-status`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|svm.uuid
|string
|path
|True
a|UUID of the SVM to which this object belongs.


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===
