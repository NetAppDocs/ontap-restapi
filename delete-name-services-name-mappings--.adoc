= Delete the name mapping configuration

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/name-services/name-mappings/{svm.uuid}/{direction}/{index}`#

*Introduced In:* 9.6

Deletes the name mapping configuration.

== Related ONTAP commands

* `vserver name-mapping delete`
