= Retrieve a plex specified by the aggregate UUID and plex name

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/storage/aggregates/{aggregate.uuid}/plexes/{name}`#

*Introduced In:* 9.6

Retrieves the plex specified by the aggregate UUID and plex name.

== Related ONTAP commands

* `storage aggregate plex show`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|aggregate.uuid
|string
|path
|True
a|Aggregate UUID


|name
|string
|path
|True
a|Plex name


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===
