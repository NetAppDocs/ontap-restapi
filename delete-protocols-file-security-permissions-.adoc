= Remove all SLAG ACLs for a path

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/protocols/file-security/permissions/{svm.uuid}/{path}`#

*Introduced In:* 9.10

Remove all SLAG ACLs for specified path. Bulk deletion is supported only for SLAG
You must keep the following points in mind while using these endpoints:

* Do not pass additional arguments that are not required.

== Related ONTAP Commands

* `vserver security file-directory remove-slag`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|path
|string
|path
|True
a|target path


|access_control
|string
|query
|False
a|Remove all SLAG ACLs. Currently bulk deletion of file-directory ACLs is not supported.

* enum: ["slag"]


|svm.uuid
|string
|path
|True
a|UUID of the SVM to which this object belongs.
