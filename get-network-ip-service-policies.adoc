= Retrieve service policies

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/network/ip/service-policies`#

*Introduced In:* 9.6

Retrieves a collection of service policies.

== Related ONTAP commands

* `network interface service-policy show`
