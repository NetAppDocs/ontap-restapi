= Retrieve WebAuthn global settings for a cluster and all SVMs

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/webauthn/global-settings`#

*Introduced In:* 9.16

Retrieve WebAuthn global settings for a cluster and all SVMs.

== Related ONTAP commands

* `security webauthn show`
