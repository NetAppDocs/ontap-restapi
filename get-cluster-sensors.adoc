[#sensors]
[.api-collapsible-fifth-title]
sensors

Environment Sensors


[cols=3*,options=header]
|===
|Name
|Type
|Description

|_links
|link:#self_link[self_link]
a|

|critical_high_threshold
|integer
a|Value above which the sensor goes into a critically high state.


|critical_low_threshold
|integer
a|Value below which the sensor goes into a critically low state.


|discrete_state
|string
a|Used to determine whether the sensor is in a normal state or any other failed state based on the value of "discrete_value" field. This field is only applicable for discrete sensors.


|discrete_value
|string
a|Applies to discrete sensors which do not have an integer value. It can have values like on, off, good, bad, ok.


|index
|integer
a|Provides the sensor ID.


|name
|string
a|Name of the sensor.


|node
|link:#node[node]
a|

|threshold_state
|string
a|Used to determine whether the sensor is in a normal state or any other failed state.


|type
|string
a|Used to determine the type of the sensor.


|value
|integer
a|Provides the sensor reading.


|value_units
|string
a|Units in which the "value" is measured. Some examples of units are mV, mW*hr, C, RPM.


|warning_high_threshold
|integer
a|Value above which the sensor goes into a warning high state.


|warning_low_threshold
|integer
a|Value below which the sensor goes into a warning low state.


|===
