= Retrieve Kerberos realms

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/nfs/kerberos/realms`#

*Introduced In:* 9.6

Retrieves Kerberos realms.

== Related ONTAP commands

* `vserver nfs kerberos realm show`

== Learn more

* link:protocols_nfs_kerberos_realms_endpoint_overview.html[DOC /protocols/nfs/kerberos/realms]
