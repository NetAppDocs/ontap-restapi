= Retrieve MetroCluster operations on the local cluster

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/cluster/metrocluster/operations`#

*Introduced In:* 9.8

Retrieves the list of MetroCluster operations on the local cluster.

== Related ONTAP Commands

* `metrocluster operation history show`

== Learn more

* link:cluster_metrocluster_operations_endpoint_overview.html[DOC /cluster/metrocluster/operations]
