= Retrieve the JIT privilege user configurations for an SVM

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/jit-privilege-users/{owner.uuid}/{account.name}/{application}`#

*Introduced In:* 9.17

Retrieves the JIT privilege user configurations for an SVM.

== Related ONTAP commands

* `security jit-privilege user show`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|owner.uuid
|string
|path
|True
a|Used to identify a cluster or an SVM


|account.name
|string
|path
|True
a|The username.


|application
|string
|path
|True
a|The name of the application.


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|account
|link:#account_reference[account_reference]
a|The name of the user.


|application
|string
a|The name of the application.


|comment
|string
a|The description of the elevation rule.


|end_time
|string
a|The end date and time of the JIT privilege session in UTC.


|jit_state
|string
a|The current status of the rule: preactive, idle, or active.


|jit_validity
|string
a|The JIT validity period on this SVM for this user.


|owner
|link:#owner[owner]
a|Owner name and UUID that uniquely identifies the JIT settings for a user.


|role
|link:#role[role]
a|The role the user will be elevated to.


|session_validity
|string
a|The session validity period on this SVM for this user.


|start_time
|string
a|The start date and time of the JIT privilege session in UTC.


|===
