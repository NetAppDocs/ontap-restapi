= Retrieve export policy rules

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/nfs/export-policies/{policy.id}/rules`#

*Introduced In:* 9.6

Retrieves export policy rules.

== Related ONTAP commands

* `vserver export-policy rule show`

== Learn more

* link:protocols_nfs_export-policies_endpoint_overview.html[DOC /protocols/nfs/export-policies]
