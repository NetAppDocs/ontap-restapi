= Retrieve Kerberos interfaces

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/nfs/kerberos/interfaces`#

*Introduced In:* 9.6

Retrieves Kerberos interfaces.

== Related ONTAP commands

* `vserver nfs kerberos interface show`

== Learn more

* link:protocols_nfs_kerberos_interfaces_endpoint_overview.html[DOC /protocols/nfs/kerberos/interfaces]
