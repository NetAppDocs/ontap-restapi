= Update NDMP configuration for an SVM

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/protocols/ndmp/svms/{svm.uuid}`#

*Introduced In:* 9.7

Updates the NDMP configuration for a specific SVM.

== Related ONTAP commands

* `vserver services ndmp modify`

== Learn more

* link:protocols_ndmp_svms_endpoint_overview.html[DOC /protocols/ndmp/svms]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|svm.uuid
|string
|path
|True
a|SVM UUID

|===

== Request Body

                

[cols=3*,options=header]
|===
|Name
|Type
|Description

|authentication_types
|array[string]
a|NDMP authentication types.


|enabled
|boolean
a|Is the NDMP service enabled on the SVM?


|svm
|link:#svm[svm]
a|SVM, applies only to SVM-scoped objects.


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "authentication_types": [
    "plaintext",
    "challenge"
  ],
  "enabled": 1,
  "svm": {
    "name": "svm1",
    "uuid": "02c9e252-41be-11e9-81d5-00a0986138f7"
  }
}
====

```

```

|===
| Error code | Description

| 65601536
| The operation is not supported because NDMP SVM-aware mode is disabled.

| 65601551
