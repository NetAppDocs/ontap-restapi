= Retrieve application component snapshots

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/application/applications/{application.uuid}/components/{component.uuid}/snapshots`#

*Introduced In:* 9.6

Retrieves snapshots of an application component.

This endpoint is only supported for Maxdata template applications.

Component snapshots are essentially more granular application snapshots. There is no difference beyond the scope of the operation.

== Learn more

* link:application_applications_application.uuid_snapshots_endpoint_overview.html[DOC /application/applications/{application.uuid}/snapshots]
* link:get-application-applications-snapshots.html[GET /application/applications/\{uuid}/snapshots]
* link:application_overview.html[DOC /application]
