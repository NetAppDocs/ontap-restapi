= Retrieve configuration information for all SVM pairs in a MetroCluster configuration

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/cluster/metrocluster/svms`#

*Introduced In:* 9.11

Retrieves configuration information for all pairs of SVMs in MetroCluster. REST /api/cluster/metrocluster/svms/?
