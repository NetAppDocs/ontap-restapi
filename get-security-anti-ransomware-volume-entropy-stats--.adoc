= Retrieve a data-entropy statistic for a volume

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/anti-ransomware/volume/entropy-stats/{volume.uuid}/{entropy_stats_type}/{timestamp}`#

*Introduced In:* 9.17

Retrieves a data-entropy statistic for the volumes.


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|volume.uuid
|string
|path
|True
a|The UUID of the volume.


|entropy_stats_type
|string
|path
|True
a|The type of entropy statistics.

* enum: ["sub_hourly", "hourly", "daily", "high_enc_pct"]


|timestamp
|string
|path
|True
a|The timestamp of the statistics.

* format: date-time


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|_links
|link:#_links[_links]
a|

|data_written_in_bytes
|integer
a|The amount of data written.


|duration
|string
a|The duration of the interval associated with this statistic. The duration is represented in ISO-8601 standard format.


|encryption_percentage
|integer
a|The percentage of data that is encrypted.


|entropy_stats_type
|string
a|Volume metrics are retrieved based on this statistic type.


|timestamp
|string
a|Start time in date-time format.


|volume
|link:#volume[volume]
a|

|===
