= Retrieve details of a specific S3 bucket snapshot

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/s3/services/{svm.uuid}/buckets/{s3_bucket.uuid}/snapshots/{uuid}`#

*Introduced In:* 9.16

Retrieves details of a specific S3 bucket snapshot.

== Related ONTAP commands

* `vserver object-store-server bucket snapshot show`

== Learn more

* link:protocols_s3_services_svm.uuid_buckets_s3_bucket.uuid_snapshots_endpoint_overview.html[DOC /protocols/s3/services/{svm.uuid}/buckets/{s3_bucket.uuid}/snapshots]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|s3_bucket.uuid
|string
|path
|True
a|The unique identifier of the bucket.


|uuid
|string
|path
|True
a|The unique identifier of the S3 bucket snapshot.


|svm.uuid
|string
|path
|True
a|UUID of the SVM to which this object belongs.


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|_links
|link:#_links[_links]
a|

|bucket_uuid
|string
a|The unique identifier of the bucket.


|create_time
|string
a|Creation time of the snapshot. It is the storage unit access time when the snapshot was created.


|name
|string
a|The name of the snapshot. Snapshot names must start with a lowercase letter, a number, or a hyphen, must end with a lowercase letter or a number, and cannot exceed 30 characters.


|svm
|link:#svm[svm]
a|Specifies the name of the SVM where this bucket exists.


|uuid
|string
a|The UUID of the snapshot in the bucket that uniquely identifies the snapshot in that bucket.


|===
