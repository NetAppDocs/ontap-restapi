= Delete the TOTP profile for a user account

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/security/login/totps/{owner.uuid}/{account.name}`#

*Introduced In:* 9.13

Deletes the TOTP profile for a user account.

== Related ONTAP commands

* `security login totp delete`
