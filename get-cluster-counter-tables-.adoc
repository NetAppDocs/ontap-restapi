= Retrieve counter table details

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/cluster/counter/tables/{name}`#

*Introduced In:* 9.11

Returns the information about a single counter table.


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|name
|string
|path
|True
a|Counter table name.


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|_links
|link:#_links[_links]
a|

|counter_schemas
|array[link:#counter_schema[counter_schema]]
a|Array of counter schema definitions.


|description
|string
a|Description of the table.


|name
|string
a|Table name.


|===
