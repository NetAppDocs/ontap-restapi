= Restore an application component snapshot

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/application/applications/{application.uuid}/components/{component.uuid}/snapshots/{uuid}/restore`#

*Introduced In:* 9.6

Restore a snapshot of an application component.

This endpoint is only supported for Maxdata template applications.

Component snapshots are essentially more granular application snapshots. There is no difference beyond the scope of the operation.
