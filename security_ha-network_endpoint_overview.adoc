= Manage HA network security
:imagesdir: ./media/

[.lead]
Modify the HA network security configuration for NVLog traffic using the security ha-network API endpoint. Retrieve the current security status or update the configuration to ensure secure communication within your environment.

== Overview

You can use the security ha-network API endpoint to modify the HA network security configuration for NVLog traffic.
The following operations are supported:

* GET to retrieve the HA network security status: GET security/ha-network
* PATCH to update the HA network security configuration: PATCH security/ha-network
