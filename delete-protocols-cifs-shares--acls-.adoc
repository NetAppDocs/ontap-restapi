= Delete a share-level ACL on a CIFS share

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/protocols/cifs/shares/{svm.uuid}/{share}/acls/{user_or_group}/{type}`#

*Introduced In:* 9.6

Deletes a share-level ACL on a CIFS share.

== Related ONTAP commands

* `vserver cifs share access-control delete`

== Learn more

* link:protocols_cifs_shares_svm.uuid_share_acls_endpoint_overview.html[DOC /protocols/cifs/shares/{svm.uuid}/\{share}/acls]
