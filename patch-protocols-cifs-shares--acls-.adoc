= Update a share-level ACL on a CIFS share

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/protocols/cifs/shares/{svm.uuid}/{share}/acls/{user_or_group}/{type}`#

*Introduced In:* 9.6

Updates a share-level ACL on a CIFS share.

== Related ONTAP commands

* `vserver cifs share access-control modify`

== Learn more

* link:protocols_cifs_shares_svm.uuid_share_acls_endpoint_overview.html[DOC /protocols/cifs/shares/{svm.uuid}/\{share}/acls]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|share
|string
|path
|True
a|Share name


|user_or_group
|string
|path
|True
a|User or group name


|type
|string
|path
|True
a|User or group type


|svm.uuid
|string
|path
|True
a|UUID of the SVM to which this object belongs.

|===

== Request Body

                

[cols=3*,options=header]
|===
|Name
|Type
|Description

|permission
|string
a|Specifies the access rights that a user or group has on the defined CIFS Share.
The following values are allowed:

* no_access    - User does not have CIFS share access
* read         - User has only read access
* change       - User has change access
* full_control - User has full_control access


|share
|string
a|CIFS share name


|sid
|string
a|Specifies the user or group secure identifier (SID).


|svm
|link:#svm[svm]
a|SVM, applies only to SVM-scoped objects.


|unix_id
|integer
a|Specifies the UNIX user or group identifier (UID/GID).


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "permission": "string",
  "share": "string",
  "sid": "S-1-5-21-256008430-3394229847-3930036330-1001",
  "svm": {
    "name": "svm1",
    "uuid": "02c9e252-41be-11e9-81d5-00a0986138f7"
  },
  "unix_id": 100
}
====

== Response

```
Status: 200, Ok
```

== Error

```
Status: Default
```

ONTAP Error Response Codes

|===
| Error Code | Description

| 655516
| The share ACL does not exist for given user and share
|===
