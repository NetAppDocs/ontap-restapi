= Retrieve a SnapLock ComplianceClock for a node

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/storage/snaplock/compliance-clocks/{node.uuid}`#

*Introduced In:* 9.7

Retrieves the SnapLock ComplianceClock for a specific node.

== Related ONTAP commands

* `snaplock compliance-clock show`

== Learn more

* link:storage_snaplock_compliance-clocks_endpoint_overview.html[DOC /storage/snaplock/compliance-clocks]

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|node.uuid
|string
|path
|True
a|Node UUID


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===
