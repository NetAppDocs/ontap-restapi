= Retrieve an external-role-mapping entry

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/external-role-mappings/{external_role}/{provider}`#

*Introduced In:* 9.16

Retrieves an external-role-mapping entry.

== Related ONTAP commands

* `security login external-role-mapping show`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|external_role
|string
|path
|True
a|External Identity provider role.


|provider
|string
|path
|True
a|Type of the external identity provider.


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|_links
|link:#self_link[self_link]
a|

|comment
|string
a|Any comment regarding this external-role-mapping entry.


|external_role
|string
a|External Identity provider role.


|ontap_role
|link:#ontap_role[ontap_role]
a|ONTAP role to map with the external identity role.

* Introduced in: 9.16


|provider
|string
a|Type of the external identity provider.


|timestamp
|string
a|Date and time indicating when this external-role-mapping entry was created.


|===
