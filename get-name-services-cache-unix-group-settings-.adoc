= Retrieve a UNIX group cache setting for an SVM

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/name-services/cache/unix-group/settings/{svm.uuid}`#

*Introduced In:* 9.11

Retrieves a unix-group cache setting for a given SVM.

== Related ONTAP commands

* `vserver services name-service cache unix-group settings show`

== Learn more

* link:name-services_cache_unix-group_settings_endpoint_overview.html[DOC /name-services/cache/unix-group/settings]
