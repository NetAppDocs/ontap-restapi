= Retrieve connection status between cache and origin volumes

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/storage/flexcache/connection-status`#

*Introduced In:* 9.18

Retrieves attributes of the connection status between cache and origin volumes.

== Related ONTAP commands

* `volume flexcache connection-status show`

== Learn more

* link:storage_flexcache_connection-status_endpoint_overview.html[DOC /storage/flexcache/connection-status]
Retrieves origin of FlexCache in the cluster.
