= Manage S3 service group configuration



== Overview

An S3 group consists of one or many users. Policies are attached to the S3 group to have access control over S3 resources at group level.

== Examples

=== Retrieving all fields for all S3 groups of an SVM

----

# The API:
/api/protocols/s3/services/{svm.uuid}/groups:

# The call:
curl -X GET "https://<mgmt-ip>/api/protocols/s3/services/12f3ba4c-7ae0-11e9-8c06-0050568ea123/groups?fields=*&return_records=true&return_timeout=15" -H "accept: application/json"
