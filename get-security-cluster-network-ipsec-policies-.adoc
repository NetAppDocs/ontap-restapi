= Retrieve the IPsec policy configuration for an ONTAP node and policy UUID

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/cluster-network/ipsec/policies/{node.uuid}/{uuid}`#

*Introduced In:* 9.19

Retrieves the IPsec policy configuration for cluster network security for a given node and policy UUID.

== Related ONTAP commands

* 'security cluster-network ipsec policy show'


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|node.uuid
|string
|path
|True
a|Node UUID.


|uuid
|string
|path
|True
a|IPsec policy UUID.

* format: uuid


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===
