= Update the NDMP mode

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/protocols/ndmp`#

*Introduced In:* 9.7

Updates the NDMP mode.

== Related ONTAP commands

* `system services ndmp node-scope-mode`

== Learn more

* link:protocols_ndmp_endpoint_overview.html[DOC /protocols/ndmp]


== Request Body

                

[cols=3*,options=header]
|===
|Name
|Type
|Description

|mode
|string
a|Indicates whether NDMP is in node-scoped or SVM-scoped mode.


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "mode": "string"
}
====
