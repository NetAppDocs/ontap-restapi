= Retrieve a Kerberos interface

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/nfs/kerberos/interfaces/{interface.uuid}`#

*Introduced In:* 9.6

Retrieves a Kerberos interface.

== Related ONTAP commands

* `vserver nfs kerberos interface show`

== Learn more

* link:protocols_nfs_kerberos_interfaces_endpoint_overview.html[DOC /protocols/nfs/kerberos/interfaces]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|interface.uuid
|string
|path
|True
a|Network interface UUID

* Introduced in: 9.7


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|_links
|link:#_links[_links]
a|

|enabled
|boolean
a|Specifies if Kerberos is enabled.


|encryption_types
|array[string]
a|

|interface
|link:#interface[interface]
a|Network interface


|machine_account
|string
a|Specifies the machine account to create in Active Directory.


|spn
|string
a|Service principal name. Valid in PATCH.


|svm
|link:#svm[svm]
a|SVM, applies only to SVM-scoped objects.


|===
