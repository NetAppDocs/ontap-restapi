= Retrieve history details for firmware update requests

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/cluster/firmware/history`#

*Introduced In:* 9.8

Retrieves the history details for firmware update requests.

== Learn more

* link:cluster_firmware_history_endpoint_overview.html[DOC /cluster/firmware/history]
