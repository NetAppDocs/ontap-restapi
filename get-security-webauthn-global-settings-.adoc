= Retrieve a WebAuthn global setting entry

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/webauthn/global-settings/{owner.uuid}`#

*Introduced In:* 9.16

Retrieves a WebAuthn global setting entry.

== Related ONTAP commands

* `security webauthn show`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|owner.uuid
|string
|path
|True
a|Used to identify a cluster or an SVM.


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|_links
|link:#self_link[self_link]
a|

|attestation
|string
a|Attestation conveyance type.


|owner
|link:#svm_reference[svm_reference]
a|SVM, applies only to SVM-scoped objects.


|require_rk
|boolean
a|Specifies whether the resident key is required.


|resident_key
|string
a|Resident key.


|scope
|string
a|Scope of the entity. Set to "cluster" for cluster owned objects and to "svm" for SVM owned objects.


|timeout
|integer
a|The timeout interval for the WebAuthn request, in milliseconds.


|user_verification
|string
a|User verification.


|===
