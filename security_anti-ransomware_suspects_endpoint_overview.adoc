= View suspect files generated by anti-ransomware
:imagesdir: ./media/

[.lead]
Retrieve a list of files recently suspected of ransomware attacks using the suspect GET API. This information can help you identify and respond to potential threats in your environment.

== Retrieving information on suspected files

The suspect GET API retrieves a list of recently suspected files potentially attacked by ransomware.
