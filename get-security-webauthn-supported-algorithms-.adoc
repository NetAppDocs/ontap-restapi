= Retrieve a WebAuthn supported algorithms entry

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/webauthn/supported-algorithms/{owner.uuid}/{algorithm.name}`#

*Introduced In:* 9.16

Retrieves a WebAuthn supported algorithms entry.

== Related ONTAP commands

* `security webauthn supported-algorithms show`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|owner.uuid
|string
|path
|True
a|Used to identify a cluster or an SVM.


|algorithm.name
|string
|path
|True
a|Algorithm name.


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|_links
|link:#self_link[self_link]
a|

|algorithm
|link:#algorithm[algorithm]
a|

|owner
|link:#svm_reference[svm_reference]
a|SVM, applies only to SVM-scoped objects.


|scope
|string
a|Scope of the entity. Set to "cluster" for cluster owned objects and to "svm" for SVM owned objects.


|===
