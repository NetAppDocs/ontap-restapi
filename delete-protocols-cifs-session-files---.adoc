= Close open files identified by SVM

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/protocols/cifs/session/files/{node.uuid}/{svm.uuid}/{identifier}/{connection.identifier}/{session.identifier}`#

*Introduced In:* 9.11

Closes open files identified by svm.uuid, file.identifier, connection.identifier and session_id.

== Related ONTAP commands

*** `vserver cifs session file close`

== Learn more

* link:protocols_cifs_session_files_endpoint_overview.html[DOC /protocols/cifs/session/files]
