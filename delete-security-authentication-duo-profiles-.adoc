= Delete a Duo profile for an SVM or cluster

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/security/authentication/duo/profiles/{owner.uuid}`#

*Introduced In:* 9.14

Deletes the Duo profile of the SVM or cluster.

== Related ONTAP commands

* `security login duo delete`
