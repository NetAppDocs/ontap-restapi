= Delete a Kerberos realm

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/protocols/nfs/kerberos/realms/{svm.uuid}/{name}`#

*Introduced In:* 9.6

Deletes a Kerberos realm.

* `vserver nfs kerberos realm delete`

== Learn more

* link:protocols_nfs_kerberos_realms_endpoint_overview.html[DOC /protocols/nfs/kerberos/realms]

|Name
|Type

|Required
|Description

|svm.uuid
|string
|path

a|SVM UUID


|name
|string
|path
|True
a|Kerberos realm

|===
