= Manage FlexCache connection status



== Overview

FlexCache is a persistent cache of an origin volume.

FlexCache supports fan-out and more than one FlexCache can be created from one origin volume.
This API retrieves the connection status between cache and origin volumes.

== FlexCache APIs

The following APIs can be used to perform operations related to FlexCache connection status:

&ndash; GET       /api/storage/flexcache/connection-status

&ndash; GET       /api/storage/flexcache/connection-status/\{node}/\{svm}/\{local_fg_msid}/\{remote_svm_uuid}/\{remote_vol_const_msid}

== Examples
