= Update the HA network security configuration

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/security/ha-network`#

*Introduced In:* 9.18

Updates the HA network security configuration.

== Optional properties

* 'enabled' - Indicates if HA network security for NVLog traffic is enabled.

== Related ONTAP commands

* 'security ha-network modify'


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|enabled
|boolean
|query
|False
a|Specifies if HA network security is enabled.

|===

a|Indicates if HA network security is enabled.

|link:#node_name[node.name]

|===

== Response

```
Status: 200, Ok
```

== Error

```
Status: Default
```

ONTAP Error Response Codes

|===
| Error Code | Description

| 70385664
| Modifying the HA network security configuration requires an effective HA version of ONTAP 9.18.1 or later.

| 70385666
| Failed to get node information for node "+++<name>+++\".+++</name>+++

| 70385667
| Failed to enable encryption on node "+++<name>+++\".+++</name>+++

| 70385671
| Failed to disable encryption on node "+++<name>+++\".+++</name>+++

| 70385673
| HA network security does not support MetroCluster configurations.

| 70385677
| Failed to modify HA network security because the "enabled" field was not specified.
|===
