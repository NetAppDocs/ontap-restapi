= Modify the anti-ransomware auto enablement setting

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/security/anti-ransomware/auto-enable`#

*Introduced In:* 9.18

API to modify the anti-ransomware auto enablement setting.


== Request Body

                

[cols=3*,options=header]
|===
|Name
|Type
|Description

|new_volume_auto_enable
|boolean
a|Auto Anti-Ransomware Protection (ARP) setting for new volumes.


|warm_up_period_applicable
|boolean
a|Indicates if the warm-up period is applicable.


|warm_up_period_completed
|boolean
a|Indicates if warm-up period has completed.


|warm_up_period_remaining_duration
|string
a|Time remaining for warm-up period completion.


|warm_up_period_total_duration
|string
a|Duration of warm-up period.


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "warm_up_period_remaining_duration": "string",
  "warm_up_period_total_duration": "string"
}
====

== Response

```
Status: 200, Ok
```

== Error

```
Status: Default, Error
```
