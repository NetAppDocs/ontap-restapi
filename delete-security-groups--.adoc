= Delete a group entry

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/security/groups/{owner.uuid}/{name}/{type}`#

*Introduced In:* 9.16

Deletes a group entry.

== Related ONTAP commands

* `security login group delete`

== Response

```
Status: 200, Ok
```

== Error

```
Status: Default
```

ONTAP Error Response Codes

|===
| Error Code | Description

| 5636244
| The group is part of the role mapping configuration. Delete the mapping first and then delete the group.
|===
