= Retrieve Vscan events

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/vscan/{svm.uuid}/events`#

*Introduced In:* 9.11

Retrieves Vscan events, which are generated by the cluster to capture important events.

== Related ONTAP commands

* `vserver vscan show-events`
