= Cancel an ongoing EBR operation

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/storage/snaplock/event-retention/operations/{id}`#

*Introduced In:* 9.7

Aborts an ongoing EBR operation.

== Related ONTAP commands

* `snaplock event-retention abort`

== Learn more

* link:storage_snaplock_event-retention_operations_endpoint_overview.html[DOC /storage/snaplock/event-retention/operations]

|Type

a|Unique identifier of an EBR operation
