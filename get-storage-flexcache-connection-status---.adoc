= Retrieve connection status between a cache and origin volume

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/storage/flexcache/connection-status/{node}/{svm}/{local_fg_msid}/{remote_svm_uuid}/{remote_vol_const_msid}`#

*Introduced In:* 9.18

Retrieves connection status between a cache and origin volume.

== Related ONTAP commands

* `volume flexcache connection-status show`

== Learn more

* link:storage_flexcache_connection-status_endpoint_overview.html[DOC /storage/flexcache/connection-status]

|Type
|In
|Required
|Description

|False
a|Specify the fields to return.
