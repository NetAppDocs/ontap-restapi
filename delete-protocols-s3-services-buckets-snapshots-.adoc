= Delete an S3 bucket snapshot

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/protocols/s3/services/{svm.uuid}/buckets/{s3_bucket.uuid}/snapshots/{uuid}`#

*Introduced In:* 9.16

Deletes S3 bucket snapshot.

== Related ONTAP commands

* `vserver object-store-server bucket snapshot delete`

== Learn more

* link:protocols_s3_services_svm.uuid_buckets_s3_bucket.uuid_snapshots_endpoint_overview.html[DOC /protocols/s3/services/{svm.uuid}/buckets/{s3_bucket.uuid}/snapshots]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|s3_bucket.uuid
|string
|path
|True
a|The unique identifier of the bucket.


|uuid
|string
|path
|True
a|The unique identifier of the S3 bucket snapshot.


|svm.uuid
|string
|path
|True
a|UUID of the SVM to which this object belongs.

|===
