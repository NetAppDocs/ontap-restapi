= Retrieve litigations under an SVM

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/storage/snaplock/litigations`#

*Introduced In:* 9.7

Retrieves the list of litigations under an SVM.

== Related ONTAP commands

* `snaplock legal-hold show`

== Learn more

* link:storage_snaplock_litigations_endpoint_overview.html[DOC /storage/snaplock/litigations]
