= Retrieve the node configuration in MetroCluster

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/cluster/metrocluster/nodes/{node.uuid}`#

*Introduced In:* 9.8

Retrieves the node configuration in the MetroCluster.

== Related ONTAP Commands

* `metrocluster node show`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|node.uuid
|string
|path
|True
a|Node UUID


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===
