= View and update IPsec configuration
:imagesdir: ./media/

[.lead]
Access and modify IPsec configurations to ensure secure data transmission within your network. Retrieve the current IPsec status or update settings as needed using the available operations.

== Overview

The following operations are supported:

* GET to retrieve the IPsec status: GET security/ipsec
* Patch to update IPsec status: PATCH security/ipsec
