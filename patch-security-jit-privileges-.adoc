= Modify JIT privilege configurations for an SVM

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/security/jit-privileges/{owner.uuid}/{application}`#

*Introduced In:* 9.17

Modifies the JIT privilege configurations for an SVM.

== Related ONTAP commands

* `security jit-privilege modify`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|owner.uuid
|string
|path
|True
a|Used to identify a cluster or an SVM.


|application
|string
|path
|True
a|Application name.

|===

== Request Body

                

[cols=3*,options=header]
|===
|Name
|Type
|Description

|default_session_validity_period
|string
a|The default session validity period on this SVM.


|max_jit_validity_period
|string
a|The maximum JIT validity period allowed on this SVM.


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "default_session_validity_period": "PT1H",
  "max_jit_validity_period": "P90D"
}
====
