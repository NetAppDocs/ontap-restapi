= Retrieve counter tables with schema definitions

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/cluster/counter/tables`#

*Introduced In:* 9.11

Returns a collection of counter tables and their schema definitions.
