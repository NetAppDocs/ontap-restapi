= Update an external-role-mapping entry

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/security/external-role-mappings/{external_role}/{provider}`#

*Introduced In:* 9.16

Updates an external-role-mapping entry.

== Related ONTAP commands

* `security login external-role-mapping modify`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|external_role
|string
|path
|True
a|External Identity provider role.


|provider
|string
|path
|True
a|Type of the external identity provider.


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Request Body

                

[cols=3*,options=header]
|===
|Name
|Type
|Description

|comment
|string
a|Any comment regarding this external-role-mapping entry.


|ontap_role
|link:#ontap_role[ontap_role]
a|ONTAP role to map with the external identity role.

* Introduced in: 9.16


|timestamp
|string
a|Date and time indicating when this external-role-mapping entry was created.


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "comment": "string",
  "ontap_role": {
    "name": "admin"
  },
  "timestamp": "string"
}
====
