= Retrieve DR group information using the DR group ID

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/cluster/metrocluster/dr-groups/{id}`#

*Introduced In:* 9.8

Retrieves the DR group information specified by the DR group id.

== Related ONTAP commands

* `metrocluster configuration-settings dr-group show`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|id
|string
|path
|True
a|

|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|_links
|link:#self_link[self_link]

|dr_pairs
|array[link:#dr_pair[dr_pair]]
a|

|id
|integer
a|DR Group ID


|partner_cluster
|link:#partner_cluster[partner_cluster]
a|Partner cluster information.


|===
