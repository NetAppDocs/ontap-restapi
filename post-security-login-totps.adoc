= Create the TOTP profile for a user account

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/security/login/totps`#

*Introduced In:* 9.13

Creates a TOTP profile for a user account.

== Required properties

* `owner.uuid` - Account owner UUID.
* `account.name` - Account user name.

== Related ONTAP commands

* `security login totp create`

== Learn more

* link:security_login_totps_endpoint_overview.html[DOC /security/login/totps]
* link:security_accounts_endpoint_overview.html[DOC /security/accounts]
