= Retrieve UNIX user information for a user and SVM

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/name-services/unix-users/{svm.uuid}/{name}`#

*Introduced In:* 9.9

Retrieves UNIX user information for the specified user and SVM.

== Related ONTAP commands

* `vserver services name-service unix-user show`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|name
|string
|path
|True
a|UNIX user name


|svm.uuid
|string
|path
|True
a|UUID of the SVM to which this object belongs.


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

== Response

```
Status: 200, Ok
```


[cols=3*,options=header]
|===
|Name
|Type
|Description

|_links
|link:#_links[_links]
a|

|full_name
|string
a|User's full name.


|id
|integer
a|UNIX user ID of the specified user.


|name
|string
a|UNIX user name to be added to the local database.


|primary_gid
|integer
a|Primary group ID to which the user belongs.


|svm
|link:#svm[svm]
a|SVM, applies only to SVM-scoped objects.


|===
