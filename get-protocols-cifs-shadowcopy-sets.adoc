= Retrieve shadow copy sets

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/cifs/shadowcopy-sets`#

*Introduced In:* 9.11

Retrieves Shadowcopy Sets.

== Related ONTAP commands

* `vserver cifs shadowcopy show-sets`

== Learn more

* link:protocols_cifs_shadow-copies_endpoint_overview.html[DOC /protocols/cifs/shadow-copies]
