= Retrieve IPsec policies

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/ipsec/policies`#

*Introduced In:* 9.8

Retrieves the collection of IPsec policies.

== Related ONTAP commands

* `security ipsec policy show`
