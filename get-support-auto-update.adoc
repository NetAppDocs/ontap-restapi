= Retrieve the current status of an automatic update feature

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/support/auto-update`#

*Introduced In:* 9.10

Retrieves the current status of the automatic update feature and the End User License Agreement (EULA).


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===
