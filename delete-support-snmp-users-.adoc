= Delete an SNMP user

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/support/snmp/users/{engine_id}/{name}`#

*Introduced In:* 9.7

Deletes an SNMP user. The engine ID can be the engine ID of the administrative SVM or a data SVM. It can also be the SNMPv3 engine ID of a remote switch.

== Related ONTAP commands

* `security login delete`
* `system snmp community delete`

== Learn more

* link:support_snmp_users_engine_id_name_endpoint_overview.html[DOC /support/snmp/users/\{engine_id}/\{name}]
