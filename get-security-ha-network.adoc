= Retrieve the HA network security configuration

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/ha-network`#

*Introduced In:* 9.18

Retrieves the HA network security configuration.

== Related ONTAP commands

* 'security ha-network show'


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

|Description

|link:#self_link[self_link]
