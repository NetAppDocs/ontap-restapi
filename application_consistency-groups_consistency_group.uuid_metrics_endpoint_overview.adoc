= Retrieve consistency group metrics



== Overview

Retrieves historical performance and capacity metrics for a consistency group.

== Examples

=== Retrieving historical performance and space metrics for a consistency group for the past day

----

# The API:
/api/application/consistency-groups/{uuid}/metrics

# The call:
curl -X GET "https://<mgmt-ip>/api/application/consistency-groups/{uuid}/metrics?interval=1d&fields=**" -H "accept: application/hal+json"
