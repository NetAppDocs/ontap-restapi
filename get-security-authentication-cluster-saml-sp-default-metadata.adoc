= Retrieve the SAML default metadata configuration

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/security/authentication/cluster/saml-sp/default-metadata`#

*Introduced In:* 9.17

Retrieves the SAML default metadata configuration.


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|scope
|string
|query
|False
a|Filter by scope


|certificate.serial_number
|string
|query
|False
a|Filter by certificate.serial_number

* maxLength: 40
* minLength: 1


|certificate.common_name
|string
|query
|False
a|Filter by certificate.common_name


|certificate.ca
|string
|query
|False
a|Filter by certificate.ca

* maxLength: 256
* minLength: 1


|host
|string
|query
|False
a|Filter by host


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===
