= Delete the DNS domain configuration for an SVM

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/name-services/dns/{uuid}`#

*Introduced In:* 9.13

Deletes DNS domain configuration of the specified SVM.

== Related ONTAP commands

* `vserver services name-service dns delete`
