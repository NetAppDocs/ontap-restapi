= Retrieve a Kerberos realm

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/nfs/kerberos/realms/{svm.uuid}/{name}`#

*Introduced In:* 9.6

Retrieves a Kerberos realm.

* `vserver nfs kerberos realm show`

== Learn more

* link:protocols_nfs_kerberos_realms_endpoint_overview.html[DOC /protocols/nfs/kerberos/realms]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|svm.uuid
|string
|path
|True
a|SVM UUID


|name
|string
|path
|True
a|Kerberos realm


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===
