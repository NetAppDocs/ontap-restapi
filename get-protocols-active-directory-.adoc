= Retrieve an Active Directory account for an SVM

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/active-directory/{svm.uuid}`#

*Introduced In:* 9.12

Retrieves the Active Directory account for a given SVM.

== Related ONTAP commands

* `vserver active-directory show`
* `vserver active-directory preferred-dc show`
* `vserver active-directory discovered-servers show`
* `vserver active-directory discovered-servers reset-servers`
* `vserver cifs security show`

== Response

```
Status: 200, Ok
```

|===
|Name
|Type
|Description

|discovered_servers
|array[link:#discovered_servers[discovered_servers]]
a|Specifies the discovered servers records.


|fqdn
|string
a|Fully qualified domain name.


|name
|string
a|Active Directory (AD) account NetBIOS name.


|organizational_unit
|string
a|Organizational unit under which the Active Directory account will be created.


|preferred_dcs
|array[link:#preferred_dcs[preferred_dcs]]
a|Specifies the preferred domain controller (DC) records.


|security
|link:#active_directory_security[active_directory_security]
a|

|svm
|link:#svm[svm]
a|SVM, applies only to SVM-scoped objects.


|===
